[h2]Description[/h2]
Thrusters built into an armor block, for large and small grids, in straight and sloped versions (4 blocks).

The original mod uses the old "legacy" Workshop format from 2015. Dedicated servers fail to download it ([i]k_EResultTimeout[/i]) and then refuse to start. This version uses the modern mod format, so servers download it normally.

[h2]How to use[/h2]
[list]
[*]All 4 blocks are in the [b]Darth Biomech Mods[/b] tab of the G menu, in a single [b]Armor Thrusters[/b] block group. The tab is shared with the updated Cryopods and Docking Ring mods.
[*]Switching from the original mod: block IDs (SubtypeIds) are unchanged. Replace the original mod with this one in your world's mod list, and do not load both at the same time. Back up your world first, because this migration has not been tested yet.
[/list]

[h2]What changed in this version[/h2]
[list]
[*]Modern mod folder layout (Data / Models / Textures, metadata.mod).
[*]File path casing fixed.
[*]Thruster type set to Ion and PCU set to 12, same as the vanilla small ion thruster. These fields did not exist in 2015.
[*]The 4 blocks are grouped into one block variant group in the G menu.
[*]Thrust, power use, size and build costs are unchanged.
[/list]

[h2]Known limitations[/h2]
[list]
[*]The large-grid blocks are named "Small Armor Thrust" / "Small Armor Sloped Thrust", like the small versions. These are the original names.
[*]Dedicated servers are not tested yet.
[/list]
