[h2]Description[/h2]
Cryogenic pods for large and small grids (8 blocks):
[list]
[*]Cryopod (functional): a cryo chamber, pressurized.
[*]Open Cryopod: a seat (cockpit).
[*]Cryopod and Cryopod Pack: decorative blocks.
[/list]

The original mod uses the old "legacy" Workshop format from 2015. Dedicated servers fail to download it ([i]k_EResultTimeout[/i]) and then refuse to start. This version uses the modern mod format, so servers download it normally.

[h2]How to use[/h2]
[list]
[*]All 8 blocks are in the [b]Darth Biomech Mods[/b] tab of the G menu, in a single [b]Cryogenic Pods[/b] block group. The tab is shared with the updated Armor Thrusters and Docking Ring mods.
[*]Switching from the original mod: block IDs (SubtypeIds) are unchanged. Replace the original mod with this one in your world's mod list, and do not load both at the same time. Back up your world first, because this migration has not been tested yet.
[/list]

[h2]What changed in this version[/h2]
[list]
[*]Modern mod folder layout (Data / Models / Textures, metadata.mod).
[*]File path casing fixed.
[*]PCU set to 15 on the functional and open pods, same as the vanilla cryo chamber and passenger seat. This field did not exist in 2015.
[*]The small-grid versions are added to the Darth Biomech Mods tab.
[*]The 8 pods are grouped into one block variant group in the G menu.
[*]Sizes and build costs are unchanged.
[/list]

[h2]Known limitations[/h2]
[list]
[*]The game logs 4 harmless MOD_ERROR messages at load time. The decorative pods include a Computer component, but they are not terminal blocks. This was already the case in the original mod, and the blocks work normally.
[*]The construction stage model of the pod pack shows a missing texture. The texture it uses was removed from the game, and the model file cannot be fixed without its source.
[*]Respawning in a pod and dedicated servers are not tested yet.
[/list]
