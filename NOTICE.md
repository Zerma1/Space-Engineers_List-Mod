images) **restent sous les droits de leur auteur**, selon les conditions sous
lesquelles il les a publiés.

Ce projet est une initiative communautaire de **maintenance** : il ne revendique
aucune propriété sur les mods d'origine.

## Règles pour la communauté

1. **Toujours créditer** l'auteur original et lier la page Workshop d'origine,
   y compris lors d'une republication sur le Workshop.
2. Si l'auteur d'origine a précisé une licence ou des conditions (description
   Workshop, fichier dans le mod), elles **priment** et doivent être recopiées dans
   le README du mod, section « Licence d'origine ».
3. Avant de republier un mod sur le Workshop, essayer de **contacter l'auteur**
   (commentaire Workshop, profil Steam) et noter la réponse ou l'absence de réponse
   dans le README du mod.
4. Si un auteur demande le retrait de son mod, il est retiré du dépôt.
