[h1]Airtight Force Field Hangar Doors (community fix)[/h1]

Airtight force field hangar doors for large and small grids, stackable from 1 to 10 blocks high. Original mod by [b]Hannobal[/b], fixed for the current version of Space Engineers.

[tr][td][b]Version[/b][/td][td]1.1[/td][/tr]

[tr][td][b]Last update[/b][/td][td]2026-11-15[/td][/tr]
[/table]

[h2]How it works[/h2]
[table]
[tr][th]Field state[/th][th]Air[/th][th]Players / objects / ships[/th][/tr]
[tr][td]Switched off or unpowered[/td][td]passes[/td][td]pass[/td][/tr]
[tr][td]Active, passable ("Open" switch on)[/td][td]blocked[/td][td]pass[/td][/tr]
[tr][td]Active, solid ("Open" switch off)[/td][td]blocked[/td][td]blocked[/td][/tr]
[/table]

[list]
[*]The terminal [b]Open[/b] switch, the toolbar / timer actions [i]Open / Open On / Open Off[/i], the use key and programmable blocks switch between solid and passable.
[*]Field colors are set through the block name: [b]co <color>[/b] (passable) and [b]cc <color>[/b] (solid). Colors: red orange yellow lime green spring cyan sky blue purple magenta pink.
[*]The state is stored in the block Custom Data as [i]ForceField: solid[/i] or [i]ForceField: passable[/i] (saved with the world, synced in multiplayer). Do not remove that line.
[*]Diagnostics: add [b]ffdebug[/b] to the block name to write its state to [i]SpaceEngineers.log[/i].
[/list]

[h2]Changes in this version[/h2]
[list]
[*]The script compiles again (missing namespace): colors, sounds and collisions work again.
[*]A switched-off or unpowered field is no longer airtight.
[*]Collision of the solid field fixed (no more jitter or violent push).
[*]Duplicate block definitions removed.
[/list]

[h2]Known limitations[/h2]
[list]
[*]A damaged (non-functional) field keeps its last airtightness.
[*]State after a world reload on a moving grid: fix not yet retested.
[*]Multiplayer and dedicated server not tested yet.
[*]Back up your world before replacing the original Workshop version with this one.
[/list]
